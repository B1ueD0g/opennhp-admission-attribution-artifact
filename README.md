# Single-request attribution of temporary network admission in OpenNHP

This repository accompanies the manuscript on attributing temporary network admission from request, action, and resource-state evidence. The solver reports the outcome of a specified request across candidate assignments consistent with a finite observation model.

The [LaTeX manuscript](manuscript/main.tex) includes the full paper, bibliography, and appendices. Build it with `cd manuscript && latexmk -pdf main.tex`.

The [reproducibility guide](REPRODUCIBILITY.md) describes the included offline artifact and its checks. The [evidence index](artifacts/manifest.json) links paper claims to materials by logical ID.

The repository begins as a private collaboration copy. Project owners can supply status for author and license details as part of release preparation. Hosted source and a reproducible offline check do not imply artifact review or paper acceptance.
